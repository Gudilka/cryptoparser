# Crypto Address Parser Telegram Bot

Telegram-бот на Python, который принимает URL, обычный текст или текстовый файл и извлекает криптовалютные адреса (BTC / ETH / TRON).

## Структура

- `bot.py` — Telegram-логика (aiogram, обработка команд/сообщений, отправка таблицы).
- `parser.py` — асинхронная загрузка страницы, очистка HTML, извлечение адресов и формирование DataFrame.
- `utils.py` — регулярные выражения, определение сети, расширяемый реестр поддерживаемых сетей.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install aiogram aiohttp beautifulsoup4 pandas
```

## Запуск

1. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Экспортируйте токен:

```bash
export TELEGRAM_BOT_TOKEN="<your_token>"
```

Альтернативно можно использовать переменную `BOT_TOKEN`.

Для Windows:

```bat
set TELEGRAM_BOT_TOKEN=<your_token>
```

Для PowerShell:

```powershell
$env:TELEGRAM_BOT_TOKEN="<your_token>"
```

3. Запустите бота:

```bash
python bot.py
```

4. В Telegram отправьте боту:
   - ссылку вида `https://example.com`, **или**
   - обычный текст сообщением, **или**
   - текстовый файл (`.txt`, `.log`, `.md`, до 2 МБ).


## Режимы ввода

- **URL**: бот скачивает HTML страницы и парсит текст страницы.
- **Текст в сообщении**: бот парсит текст напрямую без загрузки страницы.
- **Файл**: бот скачивает и декодирует файл как текст (`utf-8`, `utf-8-sig`, `cp1251`, fallback `latin-1`) и парсит содержимое.

## Формат результата

Бот возвращает:

1. Текстовую таблицу (preview) с колонками:
   - `source_id` — URL источника
   - `address` — найденный адрес
   - `chain` — `BTC` / `ETH` / `TRON` / `Unknown`
   - `context_snippet` — фрагмент текста ±50 символов вокруг совпадения
2. CSV-файл `crypto_addresses.csv` с полным результатом.

## Обработка ошибок

Реализована обработка:

- невалидного URL
- HTTP-ошибок (404, 500 и т.д.)
- сетевых ошибок подключения
- таймаута загрузки

## Ограничения логики

- **Возможны ложные срабатывания (false positives):** regex может принять случайную строку за адрес.
- **Нестандартные форматы могут быть пропущены:** поддерживаются только типовые шаблоны BTC/ETH/TRON.
- **Нельзя отличить testnet от mainnet:** определение идёт по формату, а не по сети проведения транзакций.
- **Проблемы с JS-rendered страницами:** парсер читает статический HTML, динамически подгружаемый контент может отсутствовать.
- **Нет глубокой криптографической валидации:** не проверяется checksum, существование адреса в блокчейне и т.д.

## Расширяемость

Для добавления новой сети добавьте новый `ChainPattern` в `utils.py`.
